# Разработка СВЧ-устройства: маршрут и применение САПР

1. **Маршрут разработки** СВЧ-устройства по этапам.
2. **Использование САПР на одном из этапов** — КОМПАС-3D, этап 7 «Конструкторская проработка».

Пример устройства — **аттенюатор 10 дБ, П-типа, 50 Ом**: три SMD-резистора
на микрополосковой плате. Ослабляет мощность сигнала в 10 раз и не создаёт
отражений в 50-омном тракте (защита входов измерительных приборов, развязка каскадов).

## Параметры устройства (ТЗ)

| Параметр | Значение |
|---|---|
| Ослабление | 10 дБ (в 10 раз по мощности) |
| Рабочая полоса | до 1 ГГц |
| Вход / выход | 50 Ом, разъёмы SMA |
| Макс. входная мощность | 0,1 Вт |
| Подложка | FR-4, h = 1 мм |
| Резисторы | SMD 0603: 71,2 Ом (последовательный), 2 × 96,2 Ом (шунтирующие) |
| Микрополосковая линия 50 Ом | W ≈ 1,9 мм |
| Контрольные параметры | S21 = −10 дБ, S11 ≤ −20 дБ |

Схема (П-звено):

```
вход ●────[ 71,2 Ом ]────● выход
     │                   │
 [ 96,2 Ом ]         [ 96,2 Ом ]
     │                   │
    ─┴─ земля           ─┴─ земля
```

## Диаграммы

### Пункт 1 — маршрут разработки

![Маршрут разработки СВЧ-устройства](s1.png)

1. Техническое задание
2. Выбор конструктивной основы (микрополосок, FR-4, SMD)
3. Расчёт схемы (П-звено, табличные значения резисторов)
4. Схемотехническое моделирование (AWR / QucsStudio)
5. ЭМ-моделирование топологии (HFSS / CST)
6. Топология печатной платы (Gerber)
7. **Конструкторская проработка (КОМПАС-3D)** ← раскрыто ниже
8. Изготовление и сборка
9. Измерения на ВАЦ (NanoVNA)
10. Выпуск документации

Этапы 4–9 образуют цикл «модель → прототип → измерения → уточнение»:
разработка СВЧ-устройств итерационна, с первого раза измерения не сходятся с расчётом.

### Пункт 2 — КОМПАС-3D на этапе 7

![КОМПАС-3D на этапе 7 — конструкторская проработка](s2.png)

**Обоснование выбора САПР.** КОМПАС-3D (АСКОН) — отечественная машиностроительная
САПР с выпуском КД по ЕСКД. В маршруте она закрывает этап 7: корпус и крышка,
размещение платы и разъёмов, контроль сборки, чертежи и спецификация, экспорт
3D-модели. Расчёт электромагнитных полей и S-параметров КОМПАС-3D не выполняет —
это задачи специализированных СВЧ-САПР на этапах 4–5.

Шаги этапа:

1. Деталь «Корпус»: эскиз → выдавливание → вырез полости
   (глубина = толщина платы + зазор под компоненты).
2. Бобышки M2, отверстия под SMA, винты крышки, канавка экранирования.
   Резонансы полости выбираются выше рабочего диапазона (проверка в HFSS / CST).
3. Сборка: корпус + плата (STEP из Altium) + разъёмы + крышка;
   проверка пересечений компонентов, массо-центровочные характеристики.
4. Чертежи деталей по ЕСКД, сборочный чертёж, спецификация.
5. Экспорт STEP → HFSS / CST (ЭМ-проверка устройства в корпусе),
   экспорт STL → 3D-печать макета компоновки.
